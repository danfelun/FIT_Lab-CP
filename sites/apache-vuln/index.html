🚨 Apache Vulnerable Server - DoS Lab 🚨

Simulación de Ataque de Denegación de Servicio

Este entorno simula un servidor Apache vulnerable a ataques de Denegación de Servicio (DoS). El objetivo es demostrar cómo un atacante puede saturar los recursos del servidor mediante solicitudes maliciosas, generando interrupciones en el servicio.

⚠️ Entorno vulnerable intencionalmente - Uso exclusivo educativo ⚠️

Durante este laboratorio, los estudiantes deberán identificar el servicio expuesto, analizar su comportamiento y ejecutar pruebas controladas de explotación.
